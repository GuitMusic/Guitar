`guitar.sf3` is a small sound bank made for this app:

- Programs 25 (steel) and 24 (nylon): one recording per note from E2 to E6, from the
  FluidR3 GM SoundFont by Frank Wen (MIT), as rendered in the soundfont-for-samplers
  package (MIT). See FluidR3-samples-LICENSE.txt.
- Programs 27 (steel) and 28 (nylon), and the metronome click: from GeneralUser GS 1.471
  by S. Christian Collins (http://www.schristiancollins.com). See GeneralUser-GS-LICENSE.txt.

Samples are Ogg Vorbis compressed (SoundFont 3) so the file stays under 3 MB.
